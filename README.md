# lab1_algorithms_on_matrices
Репозиторій для виконання 1 лабораторної роботи з предмету "Алгоритми та складність"

Варіант 3: матриці в стилі `T**`, комплекснозначні матриці (`Complex<double>`, `Complex<float>`).

## Структура
- `Complex.h` — власна реалізація комплексних чисел.
- `Matrix.h` — власна реалізація матриці `Matrix<T>` у стилі `T**` та оголошення алгоритмів.
- `Strassen.cpp` — задача 1: алгоритм Штрассена (будь-який розмір через динамічне доповнення нулями, перехід на звичайне множення при N <= 32/64).
- `GaussJordan.cpp` — задача 2: обернена матриця методом Гаусса-Жордана.
- `LU.cpp` — задача 3: обернена матриця методом LU-розкладання.
- `main.cpp` — тести та вимірювання часу.

## Задача 2: метод Гаусса-Жордана
`inverseGaussJordan(A)` будує розширену матрицю `[A | E]` розміру `n x 2n` і елементарними
перетвореннями рядків приводить її до вигляду `[E | A^-1]`. Для кожного стовпця:
вибір головного елемента за найбільшим `abs(z)`, перестановка рядків, нормування рядка,
занулення стовпця в усіх інших рядках. Складність O(n^3).

- Якщо матриця не квадратна — `std::invalid_argument`.
- Якщо матриця вироджена — `std::runtime_error`.
- Усередині алгоритму множення матриць немає (лише операції над рядками); добуток
  `A * A^-1` у перевірці обчислюється алгоритмом Штрассена з задачі 1.

## Задача 3: метод LU-розкладання
`inverseLU(A)` виконує LUP-розклад матриці з частковим вибором головного елемента за найбільшим `abs(z)` (`P * A = L * U`), 
зберігаючи одиничну нижньотрикутну матрицю `L` та верхньотрикутну матрицю `U` в одній матриці розміру `n x n`,
після чого знаходить стовпці оберненої матриці `A^-1` розв'язанням систем `L * U * x = P * e_j` прямою та зворотною підстановкою. 
Складність O(n^3).

- Якщо матриця не квадратна — `std::invalid_argument`.
- Якщо матриця вироджена — `std::runtime_error`.
- Перевірка `A * A^-1 = E` виконується за допомогою алгоритму Штрассена з задачі 1.
